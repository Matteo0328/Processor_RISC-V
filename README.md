# Digital Systems Design Project

This repository contains the complete SystemVerilog design, simulation environment, and hardware implementation files for the Digital Systems Design and Verification using Hardware Description Languages course at KTH.

---

## Repository Tree

```text
Digital-Systems-Design-Project/
│
├── src/
│   ├── rtl/                # Synthesizable SystemVerilog source files (*.sv)
│   ├── tb/                 # Verification testbenches and test harnesses (*.sv)
│   └── constrs/            # FPGA physical pin constraints and timing files (*.xdc)
│
├── sim/                    # Simulation scripts, waveform setups, and execution artifacts
├── .gitignore              # Exclusion list for generated and temporary files
└── README.md               # Repository documentation and directory overview
